## Introduction

**Syrinx Arena** is a gaming-themed marketing website that focuses on motion and storytelling. It uses **GSAP** for smooth scroll effects, clip-path reveals, and cinematic transitions, **React 19** for a clean component architecture, and **Tailwind CSS v4** for fast, responsive styling.

It is part of the **Syrinx** collection of web and creative-tech projects by **Sudeep**.

## Tech Stack

- ⚛️ React 19
- 🌀 Tailwind CSS v4
- 🎞️ GSAP (ScrollTrigger and timelines)
- ⚡ Vite

## Features

- 🌌 Parallax hero section with layered depth
- ✂️ Clip-path transitions between sections
- 📌 Pinned scroll sections and ScrollTrigger-driven storytelling
- 🔤 Animated text reveals
- ⏱️ Reusable GSAP timelines
- 🎬 Video sections with custom play interactions
- 📱 Fully responsive across mobile, tablet, and desktop

## Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/<your-github-username>/syrinx-arena.git
cd syrinx-arena

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev

# 4. Build for production
npm run build
```
